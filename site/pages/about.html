About the project

Model with Rhino.
Work in geographic context.

Rhino.Inside-ArcGIS brings Rhino's modeling environment into ArcGIS Pro, so design geometry and spatial data can stay connected.

PurposeOriginsProject & licenseContribute

A shared place for design and GIS.

Move from feature layers to editable Rhino geometry, develop a design, then review what changed before sending updates back. Saved links and field profiles make the relationship explicit: which layers belong together, which application owns a field, and how conflicts should be handled.

Rhino runs inside the ArcGIS Pro process. Grasshopper geometry can join the workflow by baking it into a Rhino layer. The optional MCP gateway lets an agent inspect saved links and preview changes, with local review before writes.

Explore the workflow or install the add-in.

From ArcRhino to Rhino.Inside-ArcGIS.

The idea began with ArcRhino, demonstrated at the AECTech 2019 Hackathon by Amit Nambiar, Eesha Khanna, Nico Azel, Ryan Welch and Sabrina Naumovski.

This project carries that work forward for Rhino 8 and ArcGIS Pro 3.7. Thank you to the original team, to Robert McNeel & Associates for Rhino.Inside, Rhino and Grasshopper, and to Esri for ArcGIS Pro and its SDK.

Open source. Independent community project.

Maintained by Nicolas Azel. The integration is available under the MIT license; third-party components retain their own licenses. Rhino and ArcGIS Pro are separately installed, licensed products.

The public source uses synthetic test fixtures and a reviewed history. Release assets carry checksums, a source revision and validation records. See release status and supported versions.
