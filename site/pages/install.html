Installation

Install the ArcGIS Pro add-in, launch Rhino, then open the user guide alongside your project.

RequirementsDownloadInstallFirst launchUpdate or removeTroubleshooting

Check your environment.

  • Windows 11 x64 (build 22621 or later, as targeted by this add-in).
  • ArcGIS Pro 3.7, installed and licensed.
  • Rhino 8, installed and licensed. Historical host tests used Rhino 8.34.26223.11001 with ArcGIS Pro 3.7.1.1904; compile-time Rhino references remain pinned to 8.23.

Run each application once to complete its initial setup and sign-in. ArcGIS Pro 3.6 or earlier is outside this release's supported scope.

Installing a packaged add-in does not require the .NET SDK or Visual Studio. Building from source requires the .NET 10 SDK and the ArcGIS Pro SDK build targets.

{{release-panel}}

Each installer is pinned to a named GitHub release, with its own checksum and release notes. Do not use the GitHub “Source code” ZIP as an installer.

Install the add-in.

  1. Save your work and close ArcGIS Pro.
  2. Download the .esriAddinX asset and SHA256SUMS.txt from the same release.
  3. Optionally check the download in PowerShell:
    Get-FileHash .\RhinoInside.ArcGISPro-v{{version}}.esriAddinX -Algorithm SHA256
    Compare the result with the checksum supplied for that release.
  4. Double-click the .esriAddinX file. Review the name and version in the Esri ArcGIS Add-In Installation Utility, then select Install Add-In.
  5. Start ArcGIS Pro. In Settings → Add-In Manager, confirm that Rhino.Inside for ArcGIS Pro is listed.

The add-in is unsigned. If your organization permits only signed add-ins, use your normal administrator approval process.

See Esri's official add-in installation guide for installation locations and managed deployments.

Launch Rhino inside your project.

  1. Open an ArcGIS Pro project with an active map.
  2. Open the Rhino.Inside ribbon tab and its dockpane.
  3. Select Launch Rhino. Rhino opens in the ArcGIS Pro process.
  4. Confirm the earth anchor before exchanging any geometry.
  5. Follow the GIS-first or Rhino-first guide.

Begin with a copy of a project. Apply writes to the linked GIS data and Rhino document under your selected rules.

Update or remove.

Save the ArcGIS project and the Rhino .3dm, then close ArcGIS Pro before installing a newer version. Download the replacement from its named release, check the notes, and run the same installation steps.

To remove a locally installed copy, open Settings → Add-In Manager, select the add-in and use Delete this Add-In. Restart ArcGIS Pro. Shared folder installations should be managed by the folder's administrator.

If something does not load.

The Rhino.Inside tab is missing

Confirm ArcGIS Pro 3.7 and the add-in version in Add-In Manager, then restart Pro. Check whether your organization's add-in restrictions prevent it from loading.

Rhino cannot start

Open standalone Rhino 8 once to confirm installation and licensing. Restart Pro and try Launch Rhino again. A successful standalone launch checks licensing; the embedded launch still needs to succeed separately.

Geometry arrives in the wrong place

Stop before Apply. Check the source coordinate reference system, Rhino units and the earth anchor. See georeferencing.

I need to report a problem

Include the add-in version, ArcGIS Pro build, Rhino version, geometry type and the exact message. Describe the smallest repeatable workflow and whether Preview or Apply failed. Remove confidential project data before sharing an example.

MCP gateway.

Optional embedded Rhino control requires Node.js 22 or later and the matching RhinoInside-Mcp-v{{version}}.zip gateway asset when published. Check its hash in the release checksums, extract it, and configure the client to run node server.mjs with RHINOINSIDE_MCP_HOST_PID. Start Pro with RHINOINSIDE_MCP_ENABLED=1 to opt in.

Read the full MCP setup and acceptance status. The candidate currently has no certified public installer or gateway download.
