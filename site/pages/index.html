Rhino.Inside for ArcGIS Pro

Run Rhino inside ArcGIS Pro, with layer synchronization and change tracking between the applications.

What it does

  • Hosts Rhino 8 and Grasshopper inside ArcGIS Pro 3.7.
  • Links ArcGIS feature layers to Rhino layers.
  • Synchronizes geometry and attributes in either direction.
  • Places geometry using the layer coordinate system, installed ArcGIS datum transformations and Rhino's earth anchor. Missing-transform warnings must be reviewed.
  • Tracks changes and previews them before applying updates.
  • Stores layer links and field-ownership profiles with the Rhino document.
  • Includes optional embedded Rhino MCP control in this source candidate, with local review for writes. Host acceptance is pending.

Basic workflow

  1. Link a GIS layer to a Rhino layer and confirm the earth anchor.
  2. Pull the initial GIS features, or create a GIS feature class from Rhino geometry.
  3. Preview changes and inspect conflicts or warnings.
  4. Apply updates using the link's direction and ownership rules.

To use Grasshopper geometry, bake it into a Rhino layer and synchronize that layer. Dedicated Grasshopper components and direct preview in ArcGIS are planned for a later release.

See the user guide for field profiles, multiple links, conflicts and saving your work.

Supported geometry

Point Z, Polyline Z, Polygon Z, multipart polygons and Multipatch. Rhino meshes and supported 3D Breps can create Multipatch layers. Multipatch conversion is mesh-based; it does not preserve NURBS parameters, analytic surfaces or materials.

Extent/query/delta filters and per-object conflict decisions remain outside the current release.
