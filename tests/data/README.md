# Synthetic GIS fixtures

The six shapefiles in `SHP/` are generated by [`tools/generate-fixtures.py`](../../tools/generate-fixtures.py).
Their coordinates, labels and attributes are invented and are covered by this repository's MIT
license. They do not represent surveyed buildings, streets, parcels or people.

The fresh public source snapshot regenerates these six sets from that generator. Use the same
sets for embedded Rhino MCP acceptance. The adjacent ArcGISPro.MCP checkout's fixture README
currently records unknown provenance for its parcel/street/building inputs; generated massing
derived from those inputs does not establish that the whole dataset is synthetic. Those GIS files
and geodatabases are not copied into this public tree. The deterministic inputs here can be shared
with that project's future synthetic fixture suite without changing its active test fixtures.

Run the generator in a Python virtual environment with the pinned `pyshp` dependency:

```powershell
python -m venv artifacts/fixture-venv
& ./artifacts/fixture-venv/Scripts/python.exe -m pip install pyshp==2.3.1
& ./artifacts/fixture-venv/Scripts/python.exe tools/generate-fixtures.py
```

The CRS is EPSG:3857, with geometry near (1000, 1000) metres. The fixtures cover six Point Z
features, single/multipart Polyline Z, single/multipart Polygon Z, an island with a hole, and a
closed 8-vertex, 12-triangle Multipatch. Text and integer fields exercise attribute exchange;
length/area fields exercise derived metrics. The GlobalID scenarios copy them to disposable file
geodatabases. `tools/e2e.ps1` always works on scratch copies.

The historical filenames are retained for test compatibility. Earlier repository revisions
contained external GIS data; this replacement does not remove those earlier Git objects.

`SYNTHETIC.json` records the generator and all 30 fixture hashes. DBF headers use the fixed
synthetic date 2026-01-01 so regeneration is byte reproducible. Run `node tools/verify-fixtures.mjs`
to check the public input inventory without opening a GIS host.
